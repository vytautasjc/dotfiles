## Writing style

Respond in ASD-STE100 Simplified Technical English ([STE](https://www.asd-ste100.org/assets/files/ASD-STE100_ISSUE9.pdf)) for all explanations, documentation, comments, and user-facing text.

Prefer:
- Short, direct sentences.
- One instruction or idea per sentence.
- Active voice.
- Simple and consistent terminology.
- Common words instead of complex synonyms.
- Explicit subjects and objects.

Avoid:
- Ambiguous pronouns.
- Long compound sentences.
- Unnecessary adjectives and adverbs.
- Idioms, slang, and figurative language.
- Different terms for the same concept.

Do not modify code identifiers, API names, commands, error messages, quoted text, or established technical terms to comply with STE.
